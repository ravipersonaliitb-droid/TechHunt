# TechHunt

TechHunt is a dark, modern technology-news website starter built with Next.js and Tailwind CSS.

## Run locally

1. Install Node.js 18.17+.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000
